*Обоснование непокрытых тестов:* Тест-кейсы на удаление новостей и проверки с вводом невалидных дат через сложный системный календарь (ID 26, 29) временно отложены и будут проводиться вручную. ## 2. Перечень используемых инструментов с обоснованием выбора

1. **Android Studio** — официальная среда разработки для Android.
2. **Java** — язык программирования, на котором написана экосистема проекта.
3. **JUnit 4** — базовый фреймворк для написания тестов.
4. **Espresso** — основной фреймворк от Google для UI-тестов. Синхронизируется с жизненным циклом приложения.
5. **Allure Report** — инструмент для генерации наглядных отчетов о тестировании (скриншоты при падении).
6. **Git / GitHub** — система контроля версий.

## 3. Возможные риски при автоматизации

1. **Проблемы с настройкой окружения:** конфликты версий (Gradle, Espresso, Allure). Решение: соблюдение версионирования.
2. **Нестабильность тестов (Flaky tests):** тесты могут падать из-за задержек анимации. Решение: использование `IdlingResource` вместо жестких `Thread.sleep()`.
3. **Изменение ID элементов:** если разработчики изменят идентификаторы интерфейса, тесты упадут. Решение: использование Page Object паттерна.

## 4. Интервальная оценка с учётом рисков (в часах)

* Настройка тестового окружения — 8-12 часов.
* Написание чек-листа и тест-кейсов — 12-16 часов.
* Написание UI-тестов (автоматизация) — 20-30 часов.
* Настройка генерации Allure и отладка — 8-12 часов.
* Подготовка документации — 4-8 часов.
  **Итого:** от 52 до 78 часов.
