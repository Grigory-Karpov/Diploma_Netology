# Дипломный проект: Автоматизация «Мобильный хоспис»

Проект содержит UI-автотесты для Android-приложения "Мобильный хоспис", написанные на фреймворке Espresso.

## Инструкция по запуску тестов
1. Откройте проект в Android Studio.
2. Дождитесь успешной синхронизации Gradle.
3. Запустите эмулятор с Android 10 (API 29). Убедитесь, что в приложении открыт экран авторизации с пустыми полями (пользователь разлогинен).
4. В дереве проекта слева перейдите по пути: `app` -> `src` -> `androidTest` -> `java` -> `ru.iteco.fmhandroid`.
5. Нажмите правой кнопкой мыши на класс `AuthTest` и выберите `Run 'AuthTest'`.
6. Результаты тестов сформируются в виде Allure-отчета в памяти устройства.
